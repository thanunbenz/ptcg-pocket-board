# Design system

> **เอกสารนี้เป็นแนวทางระดับ UI mockup เท่านั้น**
> รายละเอียดทั้งหมด เช่น flow, จำนวนจี้, เงื่อนไขการใช้ท่า, การสลับเทิร์น
> เป็นการจำลองเพื่อโชว์หน้าตาและ interaction ไม่ใช่ source of truth ของกติกา
> AI agents หรือทีมที่จะนำ UI ชุดนี้ไปใช้ ต้องอ้างอิง **กฏของเกมและ engine จริง**
> เป็นหลัก และปรับ flow ให้ตรงกับ engine ก่อนใช้งานจริง
> สิ่งที่เขียนในเอกสารนี้เป็นเพียงภาพรวมคร่าวๆ สำหรับออกแบบ UI

สไตล์หลัก: dark, โปร่ง, มินิมอล ใช้พื้นผิวโปร่งแสง (glass) แทนพื้นทึบ และให้สีแดง/น้ำเงินบอกฝั่งผู้เล่นเท่านั้น

## ตัวอักษร

- ฟอนต์: `"Segoe UI", system-ui, sans-serif` ผ่าน `--font-sans`
- ฟอนต์สอง: Nunito ผ่าน `--font-two` (fallback เป็น Segoe UI) ใช้กับข้อความ Player 1 / Player 2 ในแถบผู้เล่น, VsIntro, ผลทอยเหรียญ และ panel ในหน้า VS
- ป้ายช่องการ์ด: 11px (จอแคบ), 15px (บอร์ดเดสก์ท็อปปรับตามสัดส่วน)
- ชื่อผู้เล่นในแถบ: 13px mobile, 15px desktop, น้ำหนัก bold
- หัวข้อ modal: 18px bold
- ชื่อเด็ค: 15px bold, จำนวนการ์ด 13px `muted`
- ปุ่ม START: 14px bold uppercase

## รัศมีและระยะ

- ช่องการ์ด: 8px (จอแคบ), สเกลตามบอร์ดบนเดสก์ท็อป
- modal: 24px, panel ในหน้า VS: 16px, แถวเด็คและแท็บ: 12px
- ระยะภายในใช้กริด 4px, ระยะห่างหลัก 8px, 12px, 16px, 20px
- เส้นขอบ modal 1px

## Interaction

- ปุ่มลูกศรใน panel Player 2 (`opponent/15` พื้น, `opponent/50` ขอบ) สลับเด็คของสองฝั่ง
- กดการ์ดใน panel ใดก็ได้เพื่อเปิดหน้าเลือกเด็คของฝั่งนั้น
- Cancel ในหน้า VS ปิด popup
- Cancel ในหน้าเลือกเด็คกลับไปหน้า VS ไม่ปิด popup
- Escape หรือคลิกพื้นหลังปิด popup
- หน้า VS ย่อการ์ดตามความสูงจอ (`calc` จาก `dvh`) เพื่อไม่ให้มีแถบเลื่อน
- หน้าเลือกเด็ค: แสดงครั้งละ 6 เด็ค (3 แถวบนเดสก์ท็อป, 6 แถวบนมือถือ) ที่เหลือเลื่อนเอา หัวข้อกับแท็บอยู่กับที่และ Cancel อยู่ขอบล่างเสมอ กริดอยู่ในกรอบเลื่อนของตัวเอง ใช้แถบเลื่อนกว้าง 10px ที่มีขอบโปร่งใส 2px เหลือหัวมน 6px สี `white/30` (hover `white/50`) พื้นหลังโปร่งใส ไม่ใช่แถบสี่เหลี่ยมเริ่มต้นของเบราว์เซอร์

## Motion

ใช้ `motion` สำหรับแอนิเมชันทั้งหมด ไม่เขียน keyframe เอง

- เปิด/ปิด modal: opacity 180ms, scale 0.98 → 1
- เปลี่ยนหน้า VS กับรายการเด็ค: fade ออก 100ms, สลับขนาด modal ตอนเนื้อหา opacity 0, แล้ว fade เข้า 100ms (ไม่เห็นการกระตุกของขนาด)
- สลับเด็คด้วยปุ่มลูกศร: fade ออก 150ms, สลับชื่อตอน opacity 0, fade เข้า 150ms
- Deck บนบอร์ดใช้ `/pick-deck/card-back.png` ซ้อน 4 ใบ (การ์ดหน้า + 3 ใบเยื้องลงขวาให้เห็นขอบเหมือนสำรับ) พร้อมป้ายจำนวนการ์ดมุมซ้ายบน พื้นดำมนตัวอักษรขาว ไม่มีไอคอน ส่วน Discard ยังเป็นหลังการ์ดลายทาง
- กด Start ในหน้า VS: ปิด popup แล้วเล่น VsIntro เต็มจอ ปิดเองที่ 3.8 วินาที หรือกดที่จอ
- hover ไพ่ในมือ Player 1: การ์ดยกขึ้นด้วยสปริงและมี preview ขนาดใหญ่กลางพื้นที่ว่างด้านซ้ายของจอ (กว้าง `min(17.5vw,30dvh)` ที่ 14.9% ของความกว้าง) เลื่อนเมาส์ออกแล้ว preview หาย
- hover ไพ่ในมือ Player 2: ยกทีละใบเหมือนกันด้วยสปริง แต่ไม่แสดงหน้าไพ่และไม่มี preview
- hover Deck ทั้งสองฝั่งจะแสดงเมนูควบคุมขนาดกะทัดรัด: ฝั่ง Player 2 เปิดทางซ้ายของกอง ฝั่ง Player 1 เปิดทางขวา และเลื่อนเมาส์จากกองไปกดในเมนูได้โดยไม่หาย
- เมนูมี DRAW (จั่ว 1 ใบเข้าฝั่งนั้น), VIEW DECK (แผงดูการ์ดที่เหลือเป็นหลังการ์ด), MULLIGAN (เก็บมือเข้ากอง สับ 2 รอบ แล้วแจกใหม่ 5 ใบ), PROBABILITIES (จำนวนคงเหลือ, ในมือ, โอกาสจั่วใบใดใบหนึ่ง)
- เส้นกลางจอมีป้ายสถานะสีขาวตัวอักษรเข้ม ทางซ้ายของปุ่ม Start ก่อนเริ่มเกมเขียน `Game not started` หลังเริ่มเกมเป็น `Player N turn` ตามเทิร์นปัจจุบัน
- ปุ่ม Start เดิมกลายเป็นปุ่มเทิร์นหลังเกมเริ่ม: ป้ายเปลี่ยนเป็น `End Turn` กดแล้วเล่น TurnChange แล้วสลับเทิร์น ระหว่างแจกการ์ดหรือ Mulligan ปุ่มกดไม่ได้ ส่วนก่อนเริ่มเกมยังเปิดหน้าเลือกเด็คเหมือนเดิม
- FAB `...` เปิดหน้าเลือกเด็คเพื่อรีเซ็ตเดโม
- TurnChange: overlay เต็มจอ ฉากหลัง `black/72` + blur 2px แถบหมุน -8 องศา สูง 24.7dvh กว้าง 150vw กลางจอที่ 45% ขอบขาว 2px P1 gradient `#123058` ไป `#0A1627` P2 `#150808` ไป `#361111` ข้อความ `PLAYER N Turn` สีขาว Segoe UI Black 900 ขนาด 8.5dvh
- คลิกการ์ดที่วางบน Active หรือ Bench เปิด CardActions: หัว `NAME` + ปุ่ม X, แถว `ABILITY` สีแดง, แถวท่า 2 แถวพร้อมดวงพลังงานเขียว (แถวแรกมีเลข 100), `Retreat` เฉพาะ Active และแถว `Status` เฉพาะ Active; คลิกนอก panel หรือ X เพื่อปิด
- เลือกท่าโจมตีจะปิด panel และขึ้นเลข `-100` สี opponent กลางช่อง Active ฝั่งตรงข้าม 900ms, Retreat สลับ Active กับ Bench ใบแรกและล้างสถานะทิ้ง
- ลากการ์ด Trainer (การ์ด abandoned-station) จากมือไปช่อง Stadium ของ Player 1 ได้, คลิกการ์ด Stadium จะขึ้น panel `NAME` + `Yes`, กด Yes แล้วการ์ดย้ายเข้า Discard และจั่ว 1 ใบ
- Discard ของ Player 1 แสดงหน้าการ์ดล่าสุดที่เข้า discard พร้อม pill จำนวนที่ขอบล่าง แบบเดียวกับเฟรม 04 has discard
- ใช้ท่าโจมตีแล้วจี้บนการ์ดที่ตีจะย้ายเข้า discard ทั้งหมด และขึ้น panel `DISCARD` แถว Bench แสดงดวงจี้ที่ทิ้งพร้อมจำนวน `n / n` และปุ่ม OK (04 Energy discard)
- กด Ability แล้ว Yes: ถ้าใน discard มีจี้อยู่ จะดึงกลับมาติด Active 1 ลูก (จี้ใน discard ลดลง 1) พร้อมอนิเมชันดวงจี้ลอยขึ้นบนการ์ด (04 Attach Energy 2)
- คลิกช่อง Discard เปิด panel `PLAYER 1 - DISCARD PILE (จำนวนการ์ด)`: ไอคอนจี้พร้อมจำนวนจี้ใน discard และรูปการ์ดที่ถูกทิ้งทั้งหมดในแนวนอน (04 show discard)
- ปุ่มทดสอบมุมซ้ายบนแบบมินิมอล (glass pill): `Get point` เพิ่มแต้มให้ฝ่ายที่ถึงเทิร์น (สูงสุด 3) และเล่นแถบเต็มความกว้างสูง 20.6dvh กลางจอ สี self/opponent ตามฝ่าย มี `PLAYER N` ตัวขาวน้ำหนัก light ทางซ้ายและวงแต้ม 3 วงทางขวา (วงที่ได้เป็นสีขาว) แถบสไลด์เข้าจากซ้าย 320ms แล้ว fade ออกพร้อมปิดที่ 1.9s; วงแหวนในแถบผู้เล่นเติมสีตามแต้ม
- ปุ่ม `End battle` เปิดหน้าจบเกมพื้น `#0D0D16`: `VICTORY` / `DEFEAT` / `DRAW` ตามแต้ม, เส้นใต้สีเขียว, การ์ด Giratina สองฝั่งพร้อมชื่อผู้เล่น, คะแนน `p1 - p2` และจำนวนเทิร์น, ปุ่ม `Play again` รีเซ็ตกลับหน้าเลือกเด็ค และ `cancel` กลับไปที่บอร์ด
- แถว Status เปิด popup ปรับสถานะของ Active: 6 ไอคอน (Poisoned, Asleep, Paralyzed, Confused, Burned, Shield) เลือกแล้วมี ring ขาว
- สถานะบน Active แสดงช่องเดียวที่ขอบซ้าย ขนาด 1.3cqw: ถ้ามีหลายสถานะจะสลับโชว์ทีละอันทุก 2s พร้อม fade เข้าเล็กน้อย, ไอคอน Shield แยกไปขอบขวากึ่งกลางแนวตั้งเพื่อไม่ทับป้าย HP
- FAB ปุ่ม `...` เปิด CoinPopup ระหว่างเกม: เหรียญกลางจอ ไม่มีฉากหลังหรี่ โยนอัตโนมัติ 1.4s แล้วขึ้นป้าย `Coins: Head` หรือ `Coins: Tail` ปิดเองที่ 3.6s หรือคลิกเพื่อปิด; FAB `Undo` เดิมเปลี่ยนเป็นปุ่ม Restart เปิดหน้าเลือกเด็ค
- TurnChange animation: ฉากหลัง fade 200ms, แถบสไลด์เข้าจากซ้ายด้วย spring 650ms, สลับเทิร์นที่ 700ms, แถบสไลด์ออกขวา 450ms เริ่มที่ 1800ms, ปิด overlay ที่ 2300ms, reduced motion เหลือ fade 150ms ไม่สไลด์
- ลากการ์ดจากมือ Player 1 ไปวางบนช่อง Active หรือ Bench ที่ว่างได้ การ์ดจะถูกย้ายจากมือเข้าช่องพร้อมป้าย HP มุมขวาบน และแถบ HP ด้านบน (เขียว > 50%, เหลือง > 20%, แดงต่ำกว่านั้น)
- การ์ดที่วางบนบอร์ดแสดงป้าย HP ที่มุมขวาบน และแถบ HP ด้านบน (เขียว > 50%, เหลือง > 20%, แดงต่ำกว่านั้น) โดยค่า HP ลดจากการโจมตี
- ลากการ์ดจากมือด้วย pointer ตรง ๆ (ไม่ใช้ ghost ของเบราว์เซอร์) ระหว่างลากการ์ดตั้งตรง เอียง 0 องศา ไม่เอาองศาพัดของมือติดมา, การ์ดที่ลากตั้ง `pointer-events: none` เพื่อให้ hit test ทะลุไปหาช่อง Active/Bench, ถ้าปล่อยบนช่องว่างจะลงช่องนั้นทันทีโดยไม่มีอนิเมชัน (exit duration 0) ถ้าปล่อยที่อื่นจะเด้งกลับที่เดิม
- hover การ์ดที่วางบนบอร์ดจะแสดง preview ใบใหญ่ทางซ้ายเหมือนการ์ดในมือ
- Energy Zone ฝั่ง Player 1 แสดงไอคอนใบไม้สีเขียวพร้อมป้าย + ลากจากโซนพลังงานไปปล่อยบนช่อง Active/Bench ของเราเพื่อติดพลังงาน (มีลูกพลังงานลอยตาม pointer ระหว่างลาก) และนับเป็นจุดพลังงานสีเขียวที่มุมล่างซ้ายของการ์ด
- แถบผู้เล่น: ชื่อผู้เล่นวางไว้ด้านนอกพ้นมือ (Player 2 ขวา, Player 1 ซ้าย) และมีป้ายจำนวนการ์ดในมือ (ไอคอนการ์ดคู่ + ตัวเลข) อยู่ฝั่งตรงข้าม อัปเดตตามจำนวนใบที่แจกจริง
- หลัง CoinToss ผลออกและปิด overlay แล้ว ระบบแจกการ์ดเข้าไพ่ในมือทั้งสองฝั่งอัตโนมัติ P1 ก่อน P2 ห่างกัน 200ms ครบ 5 รอบ รออีก 700ms, ปุ่ม Start ปิดระหว่างแจก, การ์ดฝั่งเราเปิดหน้า ฝั่งตรงข้ามคว่ำหลัง, Deck ลดจำนวนลงทุกใบ
- การ์ดบินจาก Deck เข้ามือโดยวัด offset ครั้งเดียวต่อใบ, เรียงพัด `y = |k|*4*m`, `rotate = m*k*7`, `rotateY` ฝั่งเรา 180, `perspective 900`, `originY` 1.6 / -0.6, duration 500ms easeOut

- VsIntro: แถบ Player 2 ด้านบนใช้ gradient เดียวกับแถบผู้เล่น `#140808 → #3A1111` ตกลงมาจากนอกจอด้านบน, แถบ Player 1 ด้านล่างใช้ `#113059 → #081220` เด้งขึ้นมาจากนอกจอด้านล่างแบบนุ่ม, แทบขาวคั่นกลางโผล่ที่กลางจอหลังแถบเข้าที่, อวตารเป็นวงกลมขาวขอบสีฝั่ง (แดง Player 2, น้ำเงิน Player 1), VS อยู่ในกรอบดำมนมีเงาให้เด่น, ชื่อสีขาว ขึ้นหลังแถบเข้าที่
- กดปุ่ม Start: scale 0.96 ตาม `prefers-reduced-motion`
- แสงหลังปุ่ม Start: loop 2.4s, opacity 0.35 → 0.85 → 0.35, scale 1 → 1.06 (ถ้า reduced motion หยุดที่ opacity 0.55)
- hover การ์ดในหน้า VS: `whileHover` scale 1.03, `whileTap` 0.99, 150ms

- VsIntro: overlay fade 300ms, flash ขาว 400ms, shake 550ms, แถบ Player 2 ตกลงมาจากด้านบน 600ms และแถบ Player 1 เด้งขึ้นมาจากด้านล่างด้วย spring นุ่ม, แทบขาวคั่นกลางโผล่ที่ 800ms, เนื้อหา PLAYER 2 / VS / PLAYER 1 ทยอยขึ้นที่ 1000/1150/1300ms, ประกาย 16 จุดกระพริบวน, รวม 3.8 วินาที

## Responsive

- เกณฑ์สลับบอร์ดคือ orientation: แนวตั้งใช้ `NarrowBoard`, แนวนอนใช้ `WideBoard`
- ความกว้าง modal กำหนดที่ view: `min(92vw, 370px)` สำหรับหน้า VS, `min(92vw, 620px)` เมื่อจอเตี้ย และ `min(92vw, 570px)` สำหรับรายการเด็ค
- เนื้อหาใน modal ใช้ `w-full` และเปิด `scrollbar-gutter: stable` เพื่อไม่ให้ความกว้างกระโดดตอนแถบเลื่อนโผล่
- รายการเด็คเป็น 1 คอลัมน์ต่ำกว่า 560px และ 2 คอลัมน์ตั้งแต่ 560px
- variant `short` (`max-height: 620px`) ย่อ modal: หน้า VS เรียงสอง panel แนวนอน, รายการเด็คเป็น 3 คอลัมน์เมื่อกว้างพอ, ลดระยะห่าง
- modal สูงไม่เกิน `92dvh` และเลื่อนภายในถ้าเนื้อหายาวกว่า
- บอร์ดเดสก์ท็อปยึดความสูงจอ ใช้พื้นที่ 88.5% ของช่องระหว่างแถบผู้เล่น เผื่อที่ให้ไพ่ในมือ และครอปเฉพาะพื้นว่างด้านข้าง ไม่มีสกอร์ล
